Especificaciones de Base de Datos

Prueba Técnica Agrícola

Objetivo

El objetivo de esta sección es que el candidato genere el script DDL (Data Definition Language) para la creación de las tablas necesarias en la base de datos.

Nota importante: El sistema backend asume que estas tablas ya existen (no se deben ejecutar migraciones de frameworks como Laravel). Puedes utilizar el motor de base de datos relacional de tu preferencia (SQL Server, MySQL, PostgreSQL, etc.), siempre y cuando respetes la estructura, relaciones, índices y restricciones descritas a continuación.

Estructura de Tablas

1 Tabla: responsables

Almacena la información de los responsables asignados a las operaciones agrícolas.

Campo Tipo de Dato (Genérico) Longitud Max. Nulo Restricciones / Notas
id Entero - NO Clave Primaria (Primary Key). Auto-incremental.
nombre Cadena de texto 150 NO
apellido Cadena de texto 150 SI
correo Cadena de texto 255 SI
telefono Cadena de texto 30 SI
estatus Booleano / Bit - NO Valor por defecto: 1 (Activo / True).
created_at Fecha y hora (Timestamp) - SI
updated_at Fecha y hora (Timestamp) - SI

Índices Requeridos:

  • Índice en la columna estatus.

2 Tabla: haciendas

Almacena la información de las fincas o haciendas principales.

Campo Tipo de Dato (Genérico) Longitud Max. Nulo Restricciones / Notas
id Entero - NO Clave Primaria (Primary Key). Auto-incremental.
nombre Cadena de texto 200 NO
ubicacion Cadena de texto 255 SI
estatus Booleano / Bit - NO Valor por defecto: 1 (Activo / True).
created_at Fecha y hora (Timestamp) - SI
updated_at Fecha y hora (Timestamp) - SI

Índices Requeridos:

  • Índice en la columna estatus.

3 Tabla: lotes

Almacena las subdivisiones (lotes) correspondientes a cada hacienda.

Campo Tipo de Dato (Genérico) Longitud Max. Nulo Restricciones / Notas
id Entero - NO Clave Primaria (Primary Key). Auto-incremental.
hacienda_id Entero - NO Clave Foránea (Foreign Key) referencia a haciendas(id).
nombre Cadena de texto 200 NO
hectareas Decimal / Numérico 12 d. / 2 dec. SI
estatus Booleano / Bit - NO Valor por defecto: 1 (Activo / True).
created_at Fecha y hora (Timestamp) - SI
updated_at Fecha y hora (Timestamp) - SI

Índices Requeridos:

  • Índice en la columna hacienda_id.
  • Índice en la columna estatus.

Entregable Esperado

Deberás proporcionar un archivo con extensión .sql que contenga todas las sentencias de creación de las tablas (CREATE TABLE), así como las sentencias necesarias para establecer las claves foráneas, restricciones por defecto (DEFAULT) y la creación de los índices (CREATE INDEX) solicitados.
